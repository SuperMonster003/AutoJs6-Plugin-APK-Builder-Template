# 远程构建分阶段回退门槛决策

- 状态: 已采纳
- 日期: 2026/08/31
- 决策: 采用分阶段修订门槛
- 关联: ROADMAP M3-3 / M3-4 (仓库内工程), M8-2 / M8-4 (R2/R3 独立回退与放量), `docs/remote-build-rollout.md`

## 1. 背景

原放量标准要求远程构建进入 R1 前就具备宿主原有构建器回退. 但 AutoJs6 提交 `b2fd2b6ae` 已移除完整的宿主进程内
`ApkBuilder`; 现有同名代码是远程协议兼容适配器. 历史提交 `46ef1ed45` 的本地回退依赖后来被移除的实现, 不能直接视为
当前可用能力.

因此当前有三个事实必须同时成立:

1. 远程路径需要尽早通过真实用户形态的显式试用收集稳定性与性能证据;
2. 在没有第二条构建路径时, 远程失败不能伪装成已经安全回退;
3. 默认用户不能因为实验路径或插件故障失去原本承诺的稳定打包能力.

## 2. 决策

采用分阶段修订门槛, 将 R1 的显式实验资格与 R2/R3 的独立回退资格分开.

### 2.1 R1 明确试用

R1 允许在尚无独立回退实现时进行, 但必须同时满足以下限制:

- 宿主远程构建总开关默认关闭, 仅允许用户在开发者选项中明确开启;
- 插件能力声明与远程协议版本仍必须同时满足请求, 任一条件不满足都失败关闭;
- 每个请求最多尝试一次远程构建, 不自动重试, 不转入另一条构建路径;
- `NOT_AVAILABLE`, `UNSUPPORTED` 与 `FAILED` 都终止本次构建并显示可行动信息;
- `CANCELLED` 保持取消语义, 不触发任何回退;
- 输出先写入同目录临时文件并校验, 只有成功才原子替换目标, 失败时保留已有产物;
- 仅记录协议版本, 终态, 阶段, 耗时, 输出大小与枚举化错误分类; 不接收或记录路径, 项目正文, provider 原始消息,
  签名口令或 TypeScript 暂存密钥;
- R1 代码合入不等于 R1 已开始. G1, G5 与其余 R1 资格证据未满足前, 官方插件能力仍保持关闭.

关闭总开关会停止新的远程构建调用. 在当前架构中这也意味着没有 APK 构建执行路径, 所以它只是 R1 的紧急停止手段,
不是用户可用的构建回退.

### 2.2 R2 / R3 独立回退硬门槛

进入 R2 前必须实现并验证一条真正独立于失败远程会话的安全构建路径. 它可以是恢复并长期维护的宿主本地构建器, 也可以是
另行评审通过的独立构建实现, 但必须满足:

- 远程插件进程死亡, Binder 失联或协议不可用时仍可工作;
- 与远程路径不共享会造成同因失败的关键实现和瞬态状态;
- 每个用户请求最多一次远程尝试和一次回退尝试, 两者共享取消状态;
- `UNSUPPORTED` 可自动回退一次; `FAILED` 仅在明确可安全重试时由用户主动回退; `CANCELLED`, 完整性失败和签名失败不回退;
- 产物在安装, 启动, 主脚本执行, 元数据, 签名和升级路径上通过等价性验证;
- 故障注入覆盖 Binder 死亡, provider 不可用, 超时, 输出损坏与回退自身失败, 且不会形成循环.

没有上述实现与证据时, R2 和 R3 均为 No-Go, 即使 R1 的试用数据良好也不能豁免.

## 3. 阶段门槛

| 阶段 | 宿主行为 | 回退要求 | 当前许可 |
|---|---|---|---|
| R0 开发者实验 | 宿主总开关默认关闭; 官方插件不上报远程能力 | 无自动回退 | 维持 |
| R1 明确试用 | 开发者显式开启; 失败停止并保留旧产物 | 可暂缺独立回退, 但必须明确告知 | 资格证据补齐后可进入 |
| R2 受控灰度 | 仅测试渠道或明确 cohort 使用远程路径 | 独立回退及一次性循环保护必须通过 | 当前禁止 |
| R3 默认启用 | 匹配插件优先远程 | 独立回退, 总开关与完整 G1-G7 证据必须持续可用 | 当前禁止 |

## 4. 被否决的解释

- **把关闭远程总开关称为回退**: 被否决. 它只能阻止新会话, 不能完成用户的构建请求.
- **R1 远程失败后静默重试同一插件**: 被否决. 同因失败概率高, 也会破坏一次尝试与错误可观测性.
- **仅恢复历史调用代码而不恢复完整构建实现**: 被否决. 历史适配器本身不构成独立路径.
- **因 R1 为显式试用而取消输出完整性要求**: 被否决. 数据损坏, 错签或敏感信息泄露在任何阶段都是立即 No-Go.

## 5. 后续决策点

R1 资格批次完成前无需决定独立回退的最终实现形态. 但开始 R2 实现前必须另立 ADR, 在“恢复宿主本地构建器”与“新的独立
安全构建路径”之间确定所有权, 维护成本, 依赖边界和生命周期. 该 ADR 不能降低本文列出的回退行为与验证要求.

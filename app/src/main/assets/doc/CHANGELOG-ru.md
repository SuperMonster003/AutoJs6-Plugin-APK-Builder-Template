# v1.0.0

###### 2026/09/10

* `Подсказка` Обычная функция упаковки теперь требует APK Builder на устройстве; старый переключатель supportsRemoteBuild остается выключенным, но больше не отключает обычную упаковку
* `Подсказка` Первый официальный выпуск независимой линии версий плагина, точно соответствующий Runtime Kit AutoJs6 v6.8.0 (versionCode 5277); составная версия плагина — 1.0.0+autojs6-6.8.0 (versionCode 527701), Центр плагинов выбирает соответствующую ABI-сборку по compat-matrix.json, а удаленная сборка по-прежнему отключена по умолчанию
* `Функция` Движок плагина стал единственным формальным путем упаковки на устройстве; AutoJs6 остается компактным и независимо проверяет каждый возвращенный APK
* `Функция` Создание и проверка BKS/JKS перенесены в плагин через версионированный API хранилища ключей с безопасным отказом
* `Функция` Добавлены SemVer 1.0.0 плагина, независимая нумерация сборок, составные имена версий и монотонные значения Android versionCode, позволяющие выпускать несколько сборок плагина для одного хоста
* `Функция` Добавлены варианты universal, arm64-v8a, armeabi-v7a, x86_64 и x86 с точным выбором ABI и резервным переходом на universal
* `Функция` Добавлены закрытый при ошибке контракт диапазона совместимости хоста и авторитетная матрица совместимости, позволяющие одной сборке плагина обслуживать явно проверенный диапазон соседних исправлений
* `Исправление` Нумерация экспериментальной удалённой сборки одного файла приведена в соответствие с прежним сборщиком; добавлена закрытая при ошибке предварительная проверка места в рабочем каталоге с перекрёстно проверенными распакованными размерами, проверенным при сборке пределом расширения шаблона и резервом 256 МиБ
* `Исправление` Устаревшие метаданные и директивы исходного кода для упаковки встроенного Node.js теперь отклоняются до BUILD/SIGN с рекомендацией перейти на внешний плагин Runtime; удалено неиспользуемое внедрение службы Manifest и разрешений переднего плана
* `Исправление` Устранена гонка между закрытием и потоком сборки в экспериментальных удалённых сеансах, из-за которой после отмены или закрытия мог заново создаваться удалённый рабочий каталог; теперь очистка ждёт завершения рабочего потока и не оставляет файлов
* `Исправление` Усилена защита экспериментальной удалённой сборки: зашифрованные временные файлы TypeScript вне списка путей отклоняются, а пользовательские хранилища ключей BKS корректно распознаются после нормализации имени файла в рабочей области
* `Исправление` Ужесточены границы входных данных экспериментальной удалённой сборки: строгая проверка типов, размеров и вложенности Parcelable/Bundle и project.json, ограничения хранилища ключей, значков и глубины/сегментов путей ZIP, а также исправления переполнения имени пакета ARSC и производного имени выходного файла
* `Исправление` Невозможность активировать плагин из центра плагинов после установки в некоторых системах
* `Улучшение` Расширить предварительную проверку архивов проекта и сборки до 262144 записей, 4 GiB в сжатом виде, 2 GiB на запись, 8 GiB после распаковки и степени сжатия 2000:1
* `Улучшение` Доверенный workflow выпуска теперь поддерживает изолированный режим кандидата, который создает пять APK с производственной подписью и evidence из закрепленного Actions-артефакта хоста без создания Release и обновления авторитетной матрицы совместимости
* `Улучшение` Унифицированы правила проверки Runtime Kit в Gradle и Python, включая хеши, размеры, обязательные файлы, записи APK и согласованность пяти вариантов
* `Улучшение` Вместе с пятью APK публикуется машиночитаемый JSON-манифест доказательств, связывающий хеши артефактов, сертификат подписи, версии плагина/хоста, диапазон совместимости, идентификаторы Runtime Kit и версии протоколов
* `Улучшение` Обновлены инструкции по установке, FAQ, репетиция выпуска и документация на 10 языках для совместимых версий, выбора ABI, восстановления после понижения версии и независимого версионирования
* `Улучшение` Унифицировать оформление README и управление версиями платформы Gradle

# v6.8.0 Alpha5

###### 2026/07/16

* `Подсказка` Работает в паре с AutoJs6 v6.8.0 Alpha5; поддерживаемые версии Центра плагинов автоматически определяют сопряженную сборку, а при ручной установке используется соответствующий тег Release или суффикс autojs6-; у плагина нет значка и интерфейса, он вызывается автоматически при упаковке приложений
* `Функция` Реализовано автоматическое обнаружение плагина и чтение встроенного шаблона со стороны AutoJs6, так что функция "Упаковать приложение" больше не зависит от шаблонного APK внутри основного приложения
* `Функция` Включен полный Runtime Kit: шаблонный APK, хранилище ключей по умолчанию, метаданные среды выполнения и контрактные файлы
* `Функция` Введены автоматические проверки совместимости версий и протокола перед упаковкой с предупреждением или блокировкой при расхождении, чтобы не создавать неработающие приложения
* `Функция` Реализована проверка дайджестов SHA-256 Runtime Kit и обязательных элементов шаблона при сборке плагина, а во время работы дайджест шаблона сообщается AutoJs6 для повторной проверки
* `Функция` Внедрен экспериментальный протокол удаленной сборки, выполняющий облегченную сборку внутри процесса плагина (по умолчанию отключен, включается явно при сборке)
* `Функция` Налажен автоматизированный процесс выпуска: при публикации релиза основного репозитория AutoJs6 автоматически собирается парный APK плагина, подписывается доверенным ключом, проверяется по отпечатку сертификата и публикуется
* `Функция` Метаданные плагина, инструкции, README и CHANGELOG охватывают 10 языков: упрощенный китайский, традиционный китайский (Гонконг/Тайвань), английский, французский, испанский, японский, корейский, русский и арабский

APK Builder Template предоставляет Runtime Kit, который AutoJs6 использует при упаковке автономных приложений.

По возможности устанавливайте из современного Центра плагинов AutoJs6: он читает `compat-matrix.json`, выбирает сборку, сопряженную с этим хостом, предпочитает точный ABI устройства и при его отсутствии использует universal. При ручной установке ориентируйтесь на соответствующий тег Release или суффикс autojs6- в версии плагина; чтобы вернуться с более новой сборки, сначала удалите ее, поскольку Android не может установить пониженную версию поверх приложения. Хост обнаруживает плагин через `org.autojs.plugin.APK_BUILDER` и читает `assets/runtime-kit/template.apk`.

Runtime Kit может явно охватывать проверенный диапазон исправлений. Точный хост сборки упаковывает без предупреждения; другой хост внутри диапазона продолжает с предупреждением, а хост вне диапазона блокируется до передачи шаблона.

Упакованный Runtime Kit содержит:

- `template.apk`
- `template.apk.sha256`
- `default_key_store.bks`
- `runtime-kit.json`

Упаковка полностью выполняется в процессе плагина на том же Android-устройстве; исходный код проекта не загружается. AutoJs6 проверяет доверие и совместимость и независимо валидирует возвращенный APK. Старый переключатель `supportsRemoteBuild` остается выключенным, но не отключает этот формальный путь.
